# Task 16 - JavaScript Map and Filter Exercise

## Objective
Create a webpage that displays student records using HTML and JavaScript, with a search box that filters students by name.

## Files included
- `index.html` - Webpage structure
- `style.css` - Responsive page styling
- `script.js` - Student data, map rendering, and filter search
- `Readme.md` - Project documentation

## Student object attributes
Each student object contains `name`, `marks`, `class`, and `address`.

## Requirements implemented
1. An array of student objects is created in `script.js`.
2. The `map()` function creates the HTML for each student card.
3. The `filter()` function selects students whose names match the search text.
4. Displayed cards update as the user types.
5. The Search button also runs the search.
6. An empty-state message appears when no matching student is found.

## How to run
1. Extract the ZIP folder.
2. Open `index.html` in a web browser.
3. Type a student's name in the search box to filter the cards.
4. Open Developer Tools with `F12` and select Console to view program messages.

No Bootstrap or external JavaScript libraries are used.
