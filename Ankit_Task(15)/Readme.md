# Task 15 - JavaScript Arrays and Functions

## Objective
Create JavaScript functions that accept an array as an argument and perform operations on its elements.

## Files included
- `index.html` - Main webpage
- `style.css` - Page styling
- `script.js` - Array operations and functions
- `Readme.md` - Project documentation

## Operations
1. Find the maximum number in an array.
2. Calculate the sum of all elements.
3. Count the number of odd elements.

## Arrays used
Sample array: `[4, 8, 2, 11, 6, 7, 10]`

Dummy array: `[15, 22, 9, 4, 31, 18]`

## Function types used
- Arrow function (`findMaximum`)
- Anonymous function assigned to a variable (`calculateSum`)
- Function expression (`countOddNumbers`)

Each function receives an array as its argument and returns the calculated result.

## Sample output
For the sample array:
- Maximum number: `11`
- Sum of all elements: `48`
- Count of odd numbers: `2`

## How to run
1. Extract the ZIP folder.
2. Open `index.html` in a web browser.
3. Press `F12` or right-click and select **Inspect**.
4. Open the **Console** tab to view the results.

No Bootstrap or external JavaScript libraries are used.
