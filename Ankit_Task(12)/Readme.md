# Task 12 - JavaScript Compound Interest Calculation

## Objective
Create a JavaScript program that calculates compound interest using predefined (static) values, variables, and operators.

## Files
- `index.html` - Main webpage
- `style.css` - Page styling
- `script.js` - Compound interest calculation
- `Readme.md` - Project information

## Formula
**A = P(1 + r/n)^(nt)**

Where:
- P = Principal amount
- r = Annual rate of interest (decimal)
- n = Number of compounding periods per year
- t = Time in years
- A = Final amount

Compound Interest = A - P

## Predefined values
- Principal: ₹50,000
- Annual interest rate: 5%
- Compounding frequency: 1 time per year
- Time: 3 years

## How to run
1. Open `index.html` in a web browser.
2. Press `F12` (or right-click and select Inspect).
3. Open the **Console** tab.
4. View the principal, final amount, and compound interest.

No external libraries or frameworks are required.
