# Laundry Mart Login Page

## Task
CSS Development - Laundry Mart Login Page Using Flexbox.

## Technologies Used
- HTML5
- CSS3

## Features
- Split-screen login layout
- Laundry illustration on the left
- Email and password input fields
- Forgot password link
- Login button
- Register now link
- Responsive layout

## CSS Concepts
- Display Flex
- Justify Content
- Align Items
- Flex Direction
- Background Color
- Border Radius
- Object Fit
- Media Queries

## How to Run
Open `index.html` in a web browser. An internet connection is required to load the external laundry image.
