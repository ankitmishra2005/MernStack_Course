# Task 22 — Tailwind Hero Landing Page

## Project overview
A responsive hero landing page for **Project**, a modern AI-powered digital workspace. The page follows the supplied task brief and uses Tailwind CSS utility classes through the official CDN.

## Files
- `index.html` — page structure and Tailwind CDN setup
- `style.css` — linked stylesheet (layout styling is handled with Tailwind utilities as required)
- `script.js` — mobile navigation and fixed chat widget interactions

## Features
- Sticky navigation bar with logo, navigation links, and CTA
- Light orange-to-white gradient hero section
- Main headline, description, and two CTA buttons
- Dashboard preview built with HTML and Tailwind
- Three floating information cards: Tasks, Project Status, and Team Activity
- Fixed bottom-right chat widget
- Responsive layout for mobile, tablet, and desktop

## Run locally
1. Extract the ZIP folder.
2. Open `index.html` in a modern browser.
3. Keep an internet connection available so Tailwind CDN and remote avatar images can load.

## Notes
The dashboard preview is constructed from HTML elements and Tailwind classes rather than relying on a separate dashboard screenshot. The chat widget opens a small contact panel; its email link is a demo placeholder and should be replaced with the actual support address before production use.
