# Laundry Services - Responsive Hero Section

## Task
CSS - Laundry Services Responsive Issue

## Files
- `index.html` - page structure
- `index.css` - styling and responsive media queries

## Technologies
- HTML5
- CSS3
- Flexbox
- CSS Media Queries

## Features
- Desktop navigation bar with logo, links, and username button
- Laundry services hero section
- Responsive tablet layout with a column-based hero section
- Mobile navigation showing only the logo and username
- Responsive text and image sizing

## How to Run
Open `index.html` in a browser. An internet connection is needed to load the external laundry image.
