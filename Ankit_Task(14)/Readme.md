# Task 14 - JavaScript Loops

## Objective
Use JavaScript loops and conditional statements to perform number operations.

## Files included
- `index.html` - Main webpage
- `style.css` - Page styling
- `script.js` - JavaScript loops and calculations
- `Readme.md` - Project documentation

## Operations performed
For each predefined number, the program:
1. Finds the sum of the first n natural numbers.
2. Prints its multiplication table from 1 to 10.
3. Checks whether it is a prime number.
4. Prints all its factors.
5. Calculates the sum of its digits.
6. Checks whether it is an Armstrong number by adding the cubes of its digits.

## Five predefined variables
- `numberOne = 153`
- `numberTwo = 17`
- `numberThree = 139`
- `numberFour = 10`
- `numberFive = 370`

## Armstrong number logic
As described in the assignment example, the program uses the sum of the cubes of the digits:
`153 = 1^3 + 5^3 + 3^3`

## How to run
1. Extract the ZIP folder.
2. Open `index.html` in a browser.
3. Press `F12` (or right-click and choose Inspect).
4. Select the **Console** tab to view all results.

No Bootstrap or external JavaScript libraries are used.
