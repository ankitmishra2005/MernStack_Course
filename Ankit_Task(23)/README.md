# Greenwood Library Website — Task 23

A responsive, editorial-style landing page for Greenwood Public Library.

## Files
- `index.html` — complete website markup, Tailwind CSS CDN configuration, and small JavaScript interaction for the mobile navigation menu.

## Technologies
- HTML5
- Tailwind CSS via the official CDN
- Vanilla JavaScript

## How to run
1. Extract `Ankit_Task(23).zip`.
2. Open `index.html` in a modern web browser.
3. Keep an internet connection enabled so the Tailwind CDN and remote Unsplash images can load.

## Implemented sections
- Sticky responsive navigation with mobile menu
- Editorial hero section and library statistics
- Six interactive library section cards
- Four-image gallery with hover zoom
- Asymmetrical values/bento grid
- About section with responsive text columns
- Basic, Student, and Family membership cards
- Member testimonial with grayscale-to-color avatar hover
- Contact and opening-hours call-to-action
- Upcoming events grid
- Multi-column footer with social links

## Notes
- Styling is implemented with native Tailwind CSS utility classes; no external CSS framework or custom font is used.
- The address, contact email, social links, and event dates are illustrative placeholders and should be updated with verified library details before publishing.
- Remote images require an internet connection.
