# Task 10 - Laundry Services Hero Image Animation

## Objective
Add an attention-grabbing animation to the image in the Laundry Services hero section.

## Animation features
- The hero image follows a gentle orbit-like floating path.
- The image rotates slightly as it moves.
- The image gets squeezed and stretched at selected points using `scale(x, y)`.
- The animation loops continuously and uses a smooth easing function.
- A reduced-motion preference is respected for accessibility.

## CSS concepts used
- `@keyframes` defines the animation stages.
- `animation` applies the animation to the hero image.
- `translate()` moves the image along a small orbit-like path.
- `rotate()` adds rotation.
- `scale(x, y)` creates the squeeze/stretch effect.
- `transform-origin` sets the point around which transforms occur.

## Files
- `index.html` - Laundry Services page structure.
- `index.css` - responsive styles and animation.

## How to run
1. Extract the ZIP archive.
2. Open `index.html` in a browser.
3. Observe the hero image moving and changing shape continuously.
