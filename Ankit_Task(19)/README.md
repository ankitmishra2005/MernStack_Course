# ServiceHub – Service Booking Web App (Task 19)

A responsive service-booking interface built with HTML, CSS and vanilla JavaScript DOM manipulation.

## Files
- `index.html` – page structure, navigation, cart and booking form
- `style.css` – responsive layout and visual styling
- `script.js` – service rendering, cart operations, total calculation and form validation

## Features
- Navigation links for Home, Services, About Us and Contact Us
- Username display and logout interaction
- Service cards with images, names and prices
- Add Item and Skip Item actions
- Dynamic cart with remove controls and live total amount
- Booking form with full name, email and password validation
- Booking confirmation message after a valid submission
- Responsive layout and mobile navigation

## Run locally
1. Extract the ZIP file.
2. Open `index.html` in a modern web browser.
3. Add services to the cart and submit the booking form to test it.

## Notes
- Service images are loaded from Unsplash and need an internet connection.
- This is a front-end assignment. The booking confirmation is shown in the browser; no backend booking or email service is connected.
- The password field is included to match the assignment brief. Do not enter a real password on this demo page.
