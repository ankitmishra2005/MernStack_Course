# TuteDude MERN Stack Course — Task 19

This folder contains the JavaScript exercises shown in the Task 19 assignment screenshots. Each exercise is kept in its own directory.

## Exercises

1. **01-Compound-Interest** — Compound interest formula using predefined variables.
2. **02-Even-Odd** — Uses `if-else` to identify even and odd numbers.
3. **03-JavaScript-Loops** — Sum of first N numbers, multiplication table, prime check, factors, digit sum and Armstrong check.
4. **04-Arrays-Functions** — Array maximum, sum of elements and odd-number count using different function styles.
5. **05-Map-Filter** — Student cards rendered with `map()` and live name search using `filter()`.
6. **06-Promise-Division** — Arrow function returning a Promise, including division-by-zero rejection and five test cases.
7. **07-DOM-Manipulation** — Greeting update and interactive colour boxes using DOM events.
8. **08-Service-Booking-App** — Service cards, selection, cart, total calculation and demo booking form.

## How to run

- Extract the ZIP file.
- Open the folder for the exercise you want to test.
- Open its `index.html` file in a modern web browser.
- Open Developer Tools (usually F12) and select the **Console** tab to view `console.log()` output where applicable.

No installation or build tools are required. These are front-end practice exercises using plain HTML, CSS and JavaScript.

## Notes

- All values and student/service records are dummy data for learning purposes.
- The Service Booking App is a front-end demonstration only. It does not connect to a backend, save bookings to a database, or process payments.
- The booking form uses browser-side validation. Do not enter real passwords or sensitive information.
