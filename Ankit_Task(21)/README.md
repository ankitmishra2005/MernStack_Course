# OmniFood — Responsive Food Delivery Landing Page

A responsive, single-page landing page for a healthy food delivery brand. Built with semantic HTML, CSS Grid/Flexbox, and a small JavaScript toggle for the mobile navigation.

## Project structure
- `index.html` — page markup and mobile navigation toggle
- `style.css` — styling, layout, and responsive breakpoints
- `assets/` — local SVG illustrations and avatars

## How to run
1. Extract the ZIP.
2. Keep `index.html`, `style.css`, and `assets/` in the same project folder.
3. Open `index.html` in a modern browser. No backend or build tools are required.

## Responsive breakpoints
- Desktop: default styles (four-column city grid)
- Tablet: `max-width: 1000px` and `max-width: 834px`
- Mobile: `max-width: 600px`
- Small mobile: `max-width: 390px`

## Included sections
Header and hero, How It Works (three steps and app buttons), Our Cities (four cards), Testimonials (three quotes), Pricing Plans (Premium/Pro/Starter), and footer links/social placeholders.
