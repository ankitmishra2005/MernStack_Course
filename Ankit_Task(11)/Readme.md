# Thala 7 Sneaker Store — CSS Mini Project

## Overview
A responsive sneaker-store mini project with four connected pages:
1. Landing page
2. Product display page
3. Shopping cart page
4. Payment / checkout page

## Features
- Flexbox and CSS Grid layouts
- Responsive navigation and page layouts
- Sneaker product cards and product detail gallery
- Add-to-cart functionality using browser `localStorage`
- Quantity increase/decrease and remove item controls
- Coupon code `THALA10` for a 10% demo discount
- Order subtotal, 5% demo tax, discount and total calculation
- Checkout form with selectable Card, Crypto, Bank and Other payment tabs
- Demo-only checkout; no real payment is processed

## Project files
- `index.html` — landing page
- `product.html` — product details and image gallery
- `cart.html` — shopping cart and order summary
- `payment.html` — checkout and payment form
- `style.css` — shared responsive styling
- `script.js` — cart, coupon and checkout interactions

## Run locally
1. Extract the ZIP file.
2. Open `index.html` in a browser.
3. Navigate using the header links.
4. Add a product to the cart and test quantity, remove, coupon and checkout features.

Internet access is required for the externally hosted sneaker photos and Google Fonts.

## Demo notes
- Coupon code: `THALA10`
- Cart data is stored in the browser's local storage.
- Payment is a visual front-end demonstration only. Do not enter real card details.
