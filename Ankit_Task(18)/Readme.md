# Ankit - Task 18

## JavaScript DOM: Greeting and Interactive Colour Boxes

### Features
- Displays the heading `Hello` when the page first loads.
- Includes four boxes labelled Red, Blue, Green and Yellow.
- Clicking a box changes its background colour using JavaScript DOM manipulation.
- Accepts the user's name and updates the heading to `Hello, [name]!`.
- Responsive layout for desktop and mobile screens.

### Files
- `index.html` - page structure
- `style.css` - styling and responsive layout
- `script.js` - greeting and click-event functionality

### How to run
1. Extract `Ankit_Task(18).zip`.
2. Open the extracted folder.
3. Double-click `index.html` or open it in a browser.
4. Enter a name and click **Greet Me**.
5. Click each colour box to change its background.

No external libraries are required.
